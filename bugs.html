Issue Tracking

Found a bug in SA:GE?

We appreciate your help in making SA:GE reliable and rock-solid. All bug tracking is managed publicly on our official GitHub repository.

🐛

Submit a Bug Report on GitHub

Use our structured GitHub Issue template to report unexpected crashes, visual rendering glitches, or serialization issues.

Report a Bug on GitHub ↗ Browse Troubleshooting Guide

Before Submitting an Issue

1

Check for Updates

Verify that you are running the latest SA:GE build via the Download Page or built-in auto updater.

2

Inspect SMAPI Logs

If experiencing in-game errors, check the SMAPI console terminal or generate a log at smapi.io/log.

3

Include Steps to Reproduce

Briefly describe the exact steps taken before the error occurred, along with any relevant map or tileset details.
