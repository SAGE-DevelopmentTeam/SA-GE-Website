About the Project

About SA:GE

Stardew Authoring : Game Editor is a Stardew Valley modding tool.

What is SA:GE?

SA:GE (Stardew Authoring : Game Editor) is a visual authoring tool designed to make Stardew Valley mod creation accessible without requiring code.

The current SA:GE V3 release provides a comprehensive end-to-end visual mod development workspace—allowing creators to author Maps, Characters, Items, Cutscene Events, Tile Actions, and Translations, validate projects automatically, and build and deploy Content Patcher mods directly to Stardew Valley.

Who is SA:GE for?

  • Mod Creators & Storytellers: Anyone creating custom items, characters, dialogues, cutscenes, locations, or complete content packs for Stardew Valley.
  • Beginners: Creators who want to design mods visually without editing JSON and map files by hand.
  • Experienced Modders: Authors who want streamlined workflows for map editing, cutscene scripting, item definitions, NPC schedules, gift tastes, layer management, and SMAPI playtesting.

Core Principles

💡 Focused on Stardew Valley

SA:GE is tailored directly to Stardew Valley modding, providing dedicated visual workflows for items, characters, maps, assets, project validation, and Content Patcher mod deployment.

  • Visual-First Mod Creation: Create and edit items, characters, and maps through visual interfaces instead of manual file editing.
  • Stardew-Specific Tools: Features designed around Stardew Valley structures, such as Content Patcher integration, NPC dialogues, schedules, map layers, and warps.
  • Local & Privacy-Focused: Runs locally on your computer with zero telemetry, zero analytics, and zero required accounts.

Current Release & Evolution

SA:GE V5.1.0 delivers complete Stardew Valley 1.6 modernization and unified studio cohesion:

  • Qualified Item Routing: Modern Content Patcher routing across Data/Objects, Data/BigCraftables, and Data/Weapons with backward compatibility.
  • Recipe Studio: Dedicated Crafting and Cooking recipe authoring with authoritative 6-token Stardew 1.6 serialization syncing to Data/CraftingRecipes and Data/CookingRecipes.
  • Manifest Disk Authority: manifest.json serves as the pure source of truth for mod identity, metadata, and dependencies on disk.
  • Mail Studio Attachments: Visual authoring of complex multi-token attachment strings (%item, %money, %recipe, %quest) with live synchronization.
  • Trigger Actions Studio: Canonical Stardew 1.6 Trigger Actions schema validation and Content Patcher sync.
  • Character AI Dialogue Studio: Intelligent context compiler synthesizing character lore, voice traits, catchphrases, schedule routines, and gift tastes into structured Stardew 1.6 prompts for external AI models (ChatGPT, Claude, Gemini, Local LLMs) with zero subscriptions and zero data uploads.
  • Romance & Marriage Dialogue Separation: Full distinction between dating milestones, farm spouse routines (Characters/Dialogue/MarriageDialogue), and platonic friendship progression.
  • Portrait Token Validation & Speech Preview: Sprite sheet token mapping ($0–$N) and live speech box preview with authentic Stardew dialogue rendering and full undo/redo.
  • Real-Time Co-op Modding: Author Stardew Valley mods collaboratively with friends over LAN or Internet with instant invite codes and automatic UPnP/NAT-PMP port mapping.
  • Multi-File Safe Refactoring: Safe rename service and live dependency reference validation protecting tilesheets, maps, items, quests, and recipes.
  • Hardened Auto-Updater: Staging directory resolution, atomic backup & replace, and automatic rollback on failure.
  • Integrated SMAPI Test Pipeline: One-click mod building, clean ZIP export, and live game test sessions.

Historical milestones: SA:GE V5.0 delivered the Character AI Dialogue Studio. SA:GE V4.0 introduced real-time collaborative modding. SA:GE V3.x unified the end-to-end mod development workspace with the Event Studio, Property Catalogs, and Deep Search. SA:GE V2.0 expanded the platform into a full visual modding suite. SA:GE V1.x established the core Visual Map Editor foundation.
