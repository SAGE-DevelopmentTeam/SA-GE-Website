About the Project

About SA:GE

Stardew Authoring : Game Editor is a Stardew Valley modding tool.

What is SA:GE?

SA:GE (Stardew Authoring : Game Editor) is a visual authoring tool designed to make Stardew Valley mod creation accessible without requiring code.

The current SA:GE V2 release provides a comprehensive visual modding suite—allowing creators to author Items, Characters, Maps, and Assets, validate projects automatically, and deploy Content Patcher mods directly to Stardew Valley.

Who is SA:GE for?

  • Mod Creators & Storytellers: Anyone creating custom items, characters, dialogues, locations, or complete content packs for Stardew Valley.
  • Beginners: Creators who want to design mods visually without editing JSON and map files by hand.
  • Experienced Modders: Authors who want streamlined workflows for item definitions, NPC schedules, gift tastes, layer management, and validation.

Core Principles

💡 Focused on Stardew Valley

SA:GE is tailored directly to Stardew Valley modding, providing dedicated visual workflows for items, characters, maps, assets, project validation, and Content Patcher mod deployment.

  • Visual-First Mod Creation: Create and edit items, characters, and maps through visual interfaces instead of manual file editing.
  • Stardew-Specific Tools: Features designed around Stardew Valley structures, such as Content Patcher integration, NPC dialogues, schedules, map layers, and warps.
  • Local & Privacy-Focused: Runs locally on your computer with zero telemetry, zero analytics, and zero required accounts.

Current Release & Evolution

SA:GE V2.0.0 delivers a complete visual modding workflow:

  • Item Editor: Visual creation of custom items, categories, pricing, edibility, context tags, and custom sprite textures.
  • Character Editor: Full NPC authoring including portraits, sprites, dialogues, schedules, and gift preferences.
  • Visual Map Editor: Map authoring, multi-directory map discovery, layers, tilesets, warps, and Smart Tiles.
  • Asset Management: Centralized asset catalog with canonical path normalization and live previews.
  • Project Validation: Automated pre-deployment integrity engine checking texture paths, map files, and IDs.
  • Direct Mod Deployment: One-click deployment directly to the Stardew Valley Mods directory with standard Content Patcher formatting.
  • Character & Map Integration: NPC spawn point synchronization and companion spawns.json extraction.
  • Built-in Guide & Settings: Integrated documentation, customizable themes, and preferences.
  • Automatic Updates & Offline First: Reliable offline startup with semantic version update checking.

Historical milestone: SA:GE V1.x established the core Visual Map Editor foundation and Smart Tile terrain system.
