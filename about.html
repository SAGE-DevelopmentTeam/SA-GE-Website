Project Mission & Architecture

About SA:GE

Stardew Authoring : Game Editor is a standalone visual tool engineered to make modding Stardew Valley accessible, reliable, and visual.

What is SA:GE?

SA:GE (Stardew Authoring : Game Editor) is a desktop application designed to bridge the gap between creative game design and the technical intricacies of Stardew Valley modding.

Modding Stardew Valley has historically required coordinating multiple disconnected tools: generic tile map editors, manual JSON authoring for Content Patcher, external command-line XNB texture unpackers, and custom coordinate calculation spreadsheets.

SA:GE brings these elements together into a cohesive, purpose-built editor centered around Stardew Valley's actual game specifications.

Who is SA:GE for?

  • Mod Creators & Map Designers: Artists and authors building new custom locations, farm layouts, expansions, or visual overhauls for Stardew Valley.
  • Beginners: Creators who want to build their first custom farm or secret grove without needing to decipher raw TMX XML schemas or Content Patcher patch syntax.
  • Experienced Modders: Authors who want automated seasonal tileset extraction, visual warp validation, and guaranteed clean relative file structures for Content Patcher and SMAPI.

Core Principles

💡 “Tiled is the inspiration. Stardew Valley is the specification.”

SA:GE takes inspiration from traditional map editors like Tiled while tailoring every interface, layer rule, and asset inspector directly to Stardew Valley and Content Patcher.

  • Non-Destructive Serialization: SA:GE respects existing TMX files. Any custom XML properties, object groups, or third-party mod metadata are preserved when saving.
  • Content Patcher Native: Every project created in SA:GE is structured as a valid, distribution-ready Content Patcher mod pack.
  • Zero Tracking, Privacy-First: SA:GE operates entirely locally on your computer with zero telemetry, zero analytics, and zero required online accounts.

V1 Scope & Future Roadmap

Version 1.0 focuses specifically on the Visual Map Editor:

  • Complete 2D tile canvas with 16×16 grid geometry
  • Full Stardew layer hierarchy (Back, Buildings, Paths, Front, AlwaysFront)
  • Automatic 4-season tilesheet extraction & missing asset safeguards
  • Visual Warps, NPC Spawns, and TMX Objects
  • Automatic Content Patcher & SMAPI Mod Synchronization

Future major releases are planned to introduce visual modules for NPC Dialogue authoring, Event Scripting, and Custom Item definitions.
