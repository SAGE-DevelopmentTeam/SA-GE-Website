About the Project

About SA:GE

Stardew Authoring : Game Editor is a visual tool for creating and editing Stardew Valley maps.

What is SA:GE?

SA:GE (Stardew Authoring : Game Editor) is a visual desktop editor for creating and modifying Stardew Valley maps.

SA:GE provides an interface for placing tiles, organizing map layers, creating warps, placing NPC spawn points, and managing map objects visually without having to edit map files manually.

Who is SA:GE for?

  • Mod Creators & Map Designers: Anyone creating custom locations, farm layouts, or map modifications for Stardew Valley.
  • Beginners: Creators who want to design maps visually without editing map files by hand.
  • Experienced Modders: Authors who want dedicated tools for layer management, tileset organization, and warp configuration.

Core Principles

💡 Focused on Stardew Valley

SA:GE is tailored directly to Stardew Valley map editing, providing dedicated tools for layers, warps, properties, and tilesets.

  • Visual-First Map Editing: Create and edit maps through a visual interface instead of manual file editing.
  • Stardew-Specific Tools: Features designed around Stardew Valley map structures, such as map layers, warps, and NPC spawn placement.
  • Local & Privacy-Focused: Runs locally on your computer with zero telemetry, zero analytics, and zero required accounts.

Current Release & Future Roadmap

SA:GE V1.x focuses on the Visual Map Editor and terrain editing tools:

  • Visual Map Editor for Stardew Valley maps
  • Smart Tiles — manual terrain configuration with multiple variations and universal topology (added in V1.1.0)
  • Tileset and tile editing tools
  • Map layer visibility and editing controls
  • Warp creation and editing
  • Map objects and properties management
  • NPC spawn point placement
  • Project system and built-in guide
  • Playtesting integration and automatic updates

Future major releases are planned to introduce visual modules for NPC Dialogue authoring, Event Scripting, and Custom Item definitions.
