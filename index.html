End-to-End Development Lifecycle

The 8-Step SA:GE Modding Pipeline

From blank canvas to playable Content Patcher release, SA:GE orchestrates every phase of Stardew Valley mod creation.

1
CREATE

Initialize structured Content Patcher mod projects with standard manifest metadata and directory layout.

2
EDIT

Visually design maps, custom items, NPC personalities, portraits, sprites, schedules, cutscenes, and translations.

3
REFERENCE

Cross-link maps with character spawns, warps, shop actions, and event triggers with real-time dependency tracking.

4
VALIDATE

Run semantic diagnostics (F6) to catch missing textures, invalid warps, schema errors, and ID collisions before playing.

5
BUILD

Compile clean, staged runtime builds (F5) automatically stripping source metadata and temporary dev files.

6
TEST

Launch interactive SMAPI test sessions (F8) with live console streaming and click-to-asset error navigation.

7
EXPORT

Generate distributable release ZIP archives ready for upload to Nexus Mods or CurseForge with one click.

8
DEPLOY

Automatically stage and update your mod directly inside your local Stardew Valley Mods directory.

Got Questions?

Frequently Asked Questions

Everything you need to know about getting started with visual Stardew Valley modding.

What is SA:GE?

SA:GE (Stardew Authoring : Game Editor) is an end-to-end visual mod development workspace for Stardew Valley. It unifies visual map editing, item creation, NPC villager authoring, cutscene event scripting, tile action engineering, and live SMAPI testing into a single desktop application.

What can I create with SA:GE?

You can create custom TMX maps, full custom NPC villagers (with portraits, sprites, schedules, and gift tastes), custom items and weapons, cutscene heart events, interactive tile actions across 7 warp schemas, and multi-language translations (i18n).

Do I need to know how to code?

No! SA:GE requires zero C# knowledge or programming experience. Everything is configured visually, and SA:GE automatically generates standard Content Patcher JSON (content.json), SMAPI manifests, and TMX maps.

Where are my projects stored?

Your projects are stored in standard folders on your local hard drive (e.g. in your Documents folder). SA:GE keeps your development source files and assets completely separate from game installations and deployed mod builds.

Does SA:GE modify my Stardew installation?

No. SA:GE never modifies your base game files or executable. When you deploy or test your mod, SA:GE creates an isolated subfolder in your game's Mods directory (e.g. Mods/[CP] YourModName), which Content Patcher loads dynamically.

Can I use existing maps?

Yes. SA:GE natively opens and edits standard TMX map files. You can import existing maps from your project's assets/Maps/ or Maps/ directory, edit layers, warps, and tile properties, and save them back cleanly.

Can I edit characters and events?

Yes. The Character Editor lets you design full NPC villagers with portraits, sprites, schedules, dialogue, and gift tastes. The Event Studio allows you to visually script cutscenes, emotion portraits, camera movements, and choice branches.

Does SA:GE work offline?

Yes. SA:GE is 100% offline-first. It launches instantly without an internet connection, requires no login or user account, and includes zero telemetry, zero analytics, and zero cloud tracking.

How do updates work?

SA:GE includes a safe, quiet background update checker. When a new version is available, you can view release notes and update with one click. Every download is cryptographically verified against SHA-256 checksums before applying.
