Stardew Authoring : Game Editor
Stardew Valley modding, made visual.

SA:GE is a Stardew Valley modding tool. It is a visual authoring tool designed to make mod creation more accessible without requiring code. The current release is primarily focused on visual map editing—allowing you to design custom locations, manage layers, and paint with Smart Tiles.

Map Editor Features · V1.1.0

Visual Map Editing for Stardew Valley

Tools for creating, editing, and managing custom Stardew Valley maps.

🗺️

Visual Map Editor

Create and edit Stardew Valley maps visually instead of working directly with map files.

🌿

Smart Tiles

Create configurable terrain systems with manual tile assignment, multiple variations, configurable variation frequency, universal 3×3 topology, inner corners, and 1×–3× brush sizes.

🎨

Tileset Management

Manage and organize the tilesets used across your maps.

📚

Map Layers

Work with Stardew Valley map layers, with controls for layer visibility and editing.

🖌️

Tile Editing

Place and edit tiles on your maps using dedicated visual tools in the editor.

🌀

Warps

Create and edit map warps directly in the map editor.

🧱

Objects & Properties

Create and edit map objects and customize their properties.

👤

NPC Spawn Placement

Place and edit NPC spawn points directly on your maps.

📁

Project System

Create, open, save, and manage your SA:GE map projects.

🧪

Playtesting

Test your custom maps in Stardew Valley to verify layouts and changes.

📖

Integrated Guide & Search

Access a built-in guide with search functionality to quickly find modding help and documentation.

🔄

Automatic Updates

Stay up to date with the built-in update system.

🔭

Future Expansion Roadmap

V1 establishes the core Map Editor foundation. Future major releases are planned to introduce dedicated visual editors for NPC Dialogue & Schedules, Event Scripting, and Custom Items.

SA:GE v1.1.0 — Smart Tiles

★ Latest Release v1.1.0
Published: August 28, 2026 • Windows x64 • Portable ZIP

V1.1.0 introduces the redesigned manual Smart Tile configuration system, universal topology, tile variations, configurable variation frequency, and expanded Smart Tile painting controls.

Key Highlights:

  • Smart Tiles — manual terrain configuration for Stardew Valley tile families
  • Universal 3×3 topology with L-shaped inner corners
  • Multiple tile variations per Smart Tile position
  • Per-variation frequency controls for natural-looking terrain
  • 1×, 2×, and 3× Smart Tile brush sizes
  • Improved blob painting for correct variation distribution
  • Improved Smart Tile configuration UI
  • Self-contained portable distribution — no separate .NET installation required
