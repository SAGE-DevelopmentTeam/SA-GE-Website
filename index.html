V1 Map Editor Capabilities

Built specifically for Stardew Valley

Everything you need to build, edit, and package production-ready Content Patcher map mods.

🗺️

Visual Map Editor

Real-time hardware-accelerated 2D tile canvas with 16×16 grid rendering, live cursor coordinates, and smooth viewport navigation.

🎨

Tileset Management

Automatic extraction of vanilla Stardew XNB tilesheets into optimized PNGs with multi-tileset TSX and GID management.

📚

Stardew Map Layers

Dedicated support for standard Stardew layers (Back, Buildings, Paths, Front, AlwaysFront) with visibility toggles and editing locks.

🖌️

Tile Editing Suite

Full suite of drawing tools: Brush (B), Box Fill (U), Bucket (G), Eraser (E), Eyedropper (I), and Marquee Selection (S) with undo/redo.

🌀

Visual Warps

Point-and-click step-on warp authoring with destination map coordinate markers and purple overlay visualizers.

🧱

Tile & Object Properties

Inspect and toggle Passable, Water, Diggable, Action, and TouchAction attributes without editing raw XML strings.

👤

NPC Spawn Placement

Place character spawn pins on map tiles with directional facing indicators (Up, Right, Down, Left) and automated spawns.json syncing.

🧪

SMAPI & Content Patcher Ready

Maps and assets are automatically structured for standard Content Patcher workflows and seamless in-game testing with SMAPI.

📖

Integrated Guide & Search

Comprehensive in-app documentation with natural search to answer modding questions without technical jargon.

🔄

Automatic Updates

Built-in update system that silently checks the official manifest and provides seamless one-click desktop updates.

🍂

Seasonal Tilesheet Swapping

Automatic 4-season asset resolution across Spring, Summer, Fall, and Winter to eliminate season transition crashes.

📄

Content Patcher Packaging

Instant generation and synchronization of valid manifest.json and content.json files for immediate distribution.

🔭

Future Expansion Roadmap

V1 establishes the core Map Editor foundation. Future major releases are planned to introduce dedicated visual editors for NPC Dialogue & Schedules, Event Scripting, and Custom Items.

Documentation & Reference

Integrated, Searchable Documentation

Modding shouldn't require memorizing obscure terminology. SA:GE includes a comprehensive documentation system with natural language search designed to help you understand every tool, layer, and property.

  • Natural language search: queries like "how do I teleport the player" find Warps instantly
  • Contextual in-app guides for every layer and inspector panel
  • Diagnostic checklists for missing NPCs, black maps, and seasonal tilesets
  • Full TMX interchange and Content Patcher reference manuals
