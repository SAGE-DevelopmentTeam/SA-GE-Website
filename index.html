Complete Modding Suite · V2.0.0

Visual Mod Creation for Stardew Valley

Comprehensive visual tools for creating, editing, validating, and deploying Stardew Valley mods.

📦

Custom Item Authoring

Create and edit custom items, categories, pricing, edibility, context tags, and custom sprite textures.

👥

NPC & Character Authoring

Design custom NPCs with full identity, portraits, sprites, dialogues, schedules, and gift preferences.

🗺️

Visual Map Editor

Create and edit custom Stardew Valley maps with multi-directory discovery, layer controls, and warps.

🌿

Smart Tiles

Create configurable terrain systems with manual tile assignment, multiple variations, frequency controls, and universal 3×3 topology.

📁

Asset Management

Organize textures, portraits, sprites, and tilesets with automated canonical path resolution and live previews.

🛡️

Project Validation Engine

Automated pre-deployment integrity checking to catch missing textures, map errors, and ID conflicts.

🚀

Direct Mod Deployment

One-click mod deployment directly to the Stardew Valley Mods directory with Content Patcher synchronization.

💾

Save & Dirty State Safety

Integrated unsaved-change protection ensuring your mod assets and work are never lost.

🔗

Character & Map Linking

Link character home locations and spawn points directly to map tiles with automated companion spawn syncing.

📖

Integrated Guide & Search

Access a built-in guide with search functionality to quickly find modding help, layer references, and documentation.

🔄

Automatic Updates & Offline First

Reliable offline-first startup with built-in semantic version checking and release notifications.

⚙️

Customizable Workspace

Customizable editor themes, accent colors, window modes, and automated Stardew path detection.

🔭

Continuous Modding Evolution

V2 delivers the complete visual workflow for Items, Characters, Maps, and Assets. Future updates will continue expanding event scripting and advanced Stardew Valley modding capabilities.

SA:GE V2.0.0

★ Latest Release v2.0.0
Published: September 3, 2026 • Windows x64 • Portable ZIP

SA:GE V2 introduces a complete visual workflow for creating and managing Stardew Valley mod content without requiring users to manually edit raw files.

Key Highlights:

  • Complete Item workflow — create and edit custom items, properties, and sprites
  • Complete Character workflow — author custom NPCs with portraits, sprites, dialogues, schedules, and gift preferences
  • Complete Map workflow — visual map authoring, multi-directory map discovery, and Smart Tiles
  • Asset management — visual asset organization with automatic path resolution
  • Project validation — pre-deployment integrity checks for textures, maps, and IDs
  • Direct deployment — one-click deployment directly to the Stardew Valley Mods directory
  • Character and Map integration — NPC spawn point synchronization and map linking
  • Offline-first startup and automatic update system
  • Self-contained portable distribution — no separate .NET installation required
